## 一言で、現実の作業へ

*「治具の上の部品を取って、トレイに入れて」* Flyto2 はこれを手順に分け、必要な手順をアームに送り、実際に完了が確認できたときだけ「完了」とします。

## アームにできること

- **自分の位置を知る。** すべての関節とグリッパーの状態を、今この瞬間に。
- **教えた場所へ動く。** *ready* や *tray* などの名前付き姿勢へ。設定した可動範囲は決して超えません。
- **つかむ。** グリッパーを閉じて保持します。
- **離す。** グリッパーを開いて置きます。

## ほかのロボットと連携

アームは単独では働きません。移動ロボットが部品を運び、アームがつかみ、カメラが確認する。メーカーをまたいで、ひとつの権限ルールのもとで。

## 安全を前提に設計

- **停止は「その場で保持」。** 力が抜けて持っている物を落とすことはありません。
- **自己申告を信じない。** 結果は別のカメラが確認します。
- **決められた範囲から出ない。** すべての動作を可動範囲と照合します。
- **推測しない。** 動作中に接続が切れたら *不明* と報告し、同じ動作を繰り返しません。
- **主導権はあなたに。** アームを動かすには承認が必要で、学習し直したアームは再度承認を求めます。

## 使うほど成長

まずは手で教えた姿勢から。あとで LeRobot でより賢いつかみ方を学習させれば、同じ能力の裏側に差し込まれ、Flyto2 は新しいバージョンを使う前に承認を求めます。LeRobot で動くアームなら参加でき、最初は AM-ARM200 です。

## 4 ステップで開始

1. AM-ARM200（フォロワー約 240 ドル）と、手の届く場所に 12 V の電源スイッチを用意します。
2. アームをつなぐコンピューターに、このパックと LeRobot をインストールします。
3. `examples/am-arm200.json` をコピーし、ポートを設定して姿勢を教えます。
4. アームを Flyto2 の Space に追加し、やってほしいことを伝えます。

## 現在の状況

アーリープレビューです。すべての能力をシミュレーションのアームと Flyto2 Cloud でエンドツーエンドにテスト済み。次は実機の AM-ARM200 での動作確認です。
